# Rhine renderer Phase 1

`renderers/rhine` is an independent dynamic backend. Python remains responsible for collection, normalization, `SceneManifest` and `TimelineSequence`; this TypeScript/Vite renderer consumes a thin project contract; `psd2pen` remains the source of the accepted full transparent Box layer; Resolve remains the final edit and delivery stage.

The benchmark renderer is fixed at 1920×1080, 24 fps and 120 frames; the placeholder cut expands the same evaluator to 42 scenes and 1008 frames. `evaluate(frame)` derives every state from the integer frame, so repeated access to a frame is deterministic and does not depend on wall clock or accumulated preview time. Render mode stays frame-addressable via `?frame=57` and sets `window.__RHINE_RENDER_READY__` when the canvas is complete.

Run `npm install` and `npm run dev` from `renderers/rhine`; use `/?frame=0`, `/?frame=24` or `/?frame=48` for smoke checks. `npm test` checks the frame contract. `npm run render:phase1` captures the deterministic sequence; the final placeholder assembly is rendered from the generated 42-scene contract and includes the same archive-world treatment.

For the shared Python environment, install Conda and run `conda env create -f environment.yml`, then `conda activate arknightsclip-rhine`. In restricted workstations where named environments are not writable, the verified project-local fallback is `conda create --prefix renderers/rhine/.conda --clone arknightsclip-test-pytest -y`, followed by `conda run -p renderers/rhine/.conda python tests/run_tests.py`. Build the presentation-only contract with `python scripts/build_rhine_placeholder_project.py`. The resulting project and inventory are under `generated/rhine/final_placeholder/`; this step never writes back to `data/`.

Current limitations: the Box overlay is represented in the contract but is not composited by the browser prototype yet; the archive wall uses a lightweight canvas proxy rather than InstancedMesh; no compiler from `SceneManifest` exists in Phase 1. The official full-art cache is missing for 伊芙利特 and 安洁莉娜, so their `full_art` fields are intentionally empty rather than silently substituting another character; their accepted whole Box exports remain available. Phase 2 can add individual Pen slot export, compiler integration, all six-star batching, music modulation, Resolve integration, 4K output and chapter transitions.
