## 3. 快切节奏卡点量化与转场设计 (遵守 README 第十七/十八条规范)

* **常规快切干员（共 126 位）**：
  * 每一位干员片段的持续时间统一、绝对严格锁定为 **24 帧（1.000 秒 = 2 个音乐 Beats）**！
  * 彻底消除了手抖带来的 26f~32f 误差，卡点像机械节拍器一样平整。
* **特殊长留存干员（过门与间奏）**：
  * `000 片头`：48 帧 (2.00s)
  * `022 魁影`：98 帧 (4.08s)
  * `035 嵯峨`：46 帧 (1.92s)
  * `041 浊心斯卡蒂`：194 帧 (8.08s)
  * `046 琴柳`：123 帧 (5.12s)
  * `058 归溟幽灵鲨`：321 帧 (13.38s)
* **转场特效规则**：
  * 常规快切干员间采用 **硬切 (Hard Cut)**，保持干脆利落的“报菜名”说唱卡点风格；
  * 在长留存过渡干员（如傀影、浊心斯卡蒂、归溟幽灵鲨）的进出点配置 **平滑叠化 / 淡入淡出 (Cross Dissolve, 6~12 帧)**，避免突兀割裂。
