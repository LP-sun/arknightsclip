# Photoshop 单槽位动态操作 Spike 验收报告

- **报告时间**：2026-09-14
- **目标**：验证基于单一 PSD 模板，脱离逐个人工预制 PSD，能否仅凭结构化数据动态改写单槽位（Slot）的所有核心视觉属性并正确导出。

---

## 1. 实验对象与测试环境

- **测试模板**：`psd模板/只需要模板/能天使.psd` (209 图层母版)
- **目标槽位**：`Slot 1`（左上角 P1 博士槽位，对应原母版“覆羽惊春”）
- **渲染引擎**：`PSDToolsRenderer` (支持无头跨平台动态图层编排与文本光栅化渲染)
- **输出规格**：1920 × 1080 Full Canvas RGBA

---

## 2. 核心验证用例与互斥状态核查

### 用例 A：玩家拥有干员 (`own = True`)
- **注入数据**：`elite = 2`, `level = 83`, `potential = 4`, `no_info = False`
- **图层操作实测**：
  1. **等级文字**：原有静态文字层隐藏，在精确 BBox `(185, 228, 233, 264)` 动态绘制全新文字 `"83"`，成功呈现 `LV 83`；
  2. **精英化显隐**：`精二` 图标设为 `True`，`精一`、`精0` 设为 `False`，实现单选互斥；
  3. **潜能徽章显隐**：`潜4` 设为 `True`，`潜1`、`潜2`、`潜3`、`潜5`、`潜6` 全部设为 `False`，实现单选互斥；
  4. **NO INFO 遮罩**：`- - - NO INFO - - -` 设为 `False`，卡面正常透出显示；
- **产出资产**：[`reports/spike_slot1_own.png`](file:///E:/明日方舟报菜名/reports/spike_slot1_own.png)

### 用例 B：玩家未拥有干员 (`own = False`)
- **注入数据**：`own = False`, `no_info = True`
- **图层操作实测**：
  1. **等级区域**：`111` 底框、文字与 `LV` 全部隐藏；
  2. **精英化区域**：`01` 底框及 `精0`、`精一`、`精二` 全部隐藏；
  3. **潜能区域**：`01` 徽章底框及 `潜1~6` 全部隐藏；
  4. **NO INFO 状态**：`- - - NO INFO - - -` 设为 `True`，清晰显示缺席状态；
- **产出资产**：[`reports/spike_slot1_no_info.png`](file:///E:/明日方舟报菜名/reports/spike_slot1_no_info.png)
